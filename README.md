# Arduino UI Generator Suite 🛠️

## ✨ [**Live Demo: Try the Arduino UI Generator Suite Here!**](https://hukuton.github.io/Arduino-UI-Generator-Suite/)

A free, 100% browser-based utility suite designed for students, hobbyists, and makers. Quickly generate C++ byte arrays for Arduino displays and create high-quality mockup images for your documentation and tutorials. No backend, no installation—just click, copy, and code!

## ✨ Features

* **UNO R4 WiFi Matrix Generator:** Draw shapes on a hardware-accurate (slanted SMD LED) 12x8 matrix and instantly generate the `uint32_t` or `uint16_t` arrays for your sketch.

* **LCD Custom Character Creator:** Click to draw 5x8 pixel custom characters for standard LiquidCrystal displays.

* **7-Segment Array Generator:** Visually toggle segments to generate hex/binary codes. Supports both Common Anode and Common Cathode logic.

* **LCD Screen Mockup Tool:** Type text directly onto a simulated LCD screen (supports 16x2, 20x4, 8x2, etc.). Customize background/pixel colors and download as a crisp PNG for your project guides.

* **7-Segment Mockup Tool:** Type numbers, letters, and colons to generate a realistic multi-digit 7-segment display. Downloadable as a transparent PNG.

## ✨ How to Use

1. Visit the [Live Site](https://hukuton.github.io/Arduino-UI-Generator-Suite/).
2. Select your desired tool from the sidebar.
3. Interact with the displays by clicking pixels/segments or typing in the mockup text boxes.
4. Click **Copy Code** to paste directly into your Arduino IDE, or **Download PNG** to save a mockup image.

## 💻 Local Development

1. Clone this repository:
   \`\`\`bash
